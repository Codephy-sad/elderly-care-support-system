# Elderly Care & Support Platform

Academic stack: HTML, CSS, JavaScript, PHP, MySQL, XAMPP.

## Folder structure (Step 1)

- `assets/` — CSS, JavaScript, and images
- `config/` — database, auth, and constants
- `includes/` — shared header, footer, navbar, and helpers
- `public/` — landing, login, and register
- Role folders: `elderly/`, `family/`, `caregiver/`, `kitchen/`, `manager/`, `admin/`, `donor/`, `volunteer/`
- `database/` — MySQL schema
- `docs/` — project documentation

## Database

Target database name: `elderly_care_`

Connection template: `config/database.php` (PDO, prepared statements enabled).
